Changes

2023-06-08 1.4.3 BETA

  • Added the area type (include/exclude) to the text in the area list.
  • Added a "From screen" button to the Windows Touch output that enables easy setup from a list of available screens.
  • Clamp Windows Touch contact area to the dimensions of the screen.
  • Fixed re-use of pointer ids when using multiple Windows Touch outputs simultaneously.
  • Reset all pointer ids in the case touch injection fails.

2023-03-28 1.4.2

  • Prevent the sensor view dock window from being closed.
  • Fix an issue with files with raw distance output being loaded.

2022-10-18 1.4.1

  • Properly handle touch detection and drawing of data from 360º laser scanners.
  • Save and restore main window position.
  • Added a minimum confidence setting for the LDROBOT LD06 laser. The LD06 devices tend to erroneously report close scan points when scanning certain materials like glass, increasing the minimum confidence can improve the situation.
  • Update the view even when the sensor is not running.

2022-10-12 1.4.0

  • Hokuyo: Fixed a case where a connection failure would not cause automatic reconnection in the calibration utility.
  • Touch detector: Make the initial finding of relevant touch segments use the area settings.
  • Visualization: Show tracked but inactive touches, like when minimum touch age is not reached, in a light grey.
  • LD06: Add support for LDROBOT LD06 sensors.
  • Licensing: Add support for more relaxed online checks.

2021-10-21 1.3.1

  • Fix no touch detection when no include areas are defined.

2021-10-10 1.3.0

  • Fix crash in device / screen list when removing entries.
  • Add support for include / exclude areas relative to a screen.

2021-08-08 1.2.5

  • Update to OSCpkt version 1.2.
  • Fix various issues from code analysis.
  • Fix performance regression in Windows Touch output introduced in version 1.2.4.
  • Improve log window performance.
  • Fix lag caused by buffer bloat using LeiShen LS01B devices.
  • Updated Linux port based on Ubuntu 20.04.
  • Fix minimum touch age not working.

2020-09-14 1.2.4

  • Update Yubico PIV Tool to version 1.6.2
  • Improved dongle error logging.
  • Fixed dongle expiration.
  • Fix initialization of motion acceleration in TUIO output.
  • Fix sending TUIO cursors with 0x0 position before minimum touch age is reached.
  • Set the default minimum touch age to 0, except on Hokuyo devices where it remains 3. This reduces the time it takes to first detect a touch.
  • Fix minimum touch age parameter not being used correctly.
  • Remove fixed TUIO touch queue depth.
  • Fix initialization of velocity / motion speed of the first TUIO packet of every touch.
  • Add support for KELI LS sensors.
  • Add support for a wider range of Sick sensors.
  • Make reconnection of sensors more reliable.
  • Dropped support for 32-bit Windows & Linux platforms.
  • The Sick driver now adjusts itself so that it can handle any incoming scan data format, regardless of the program settings.
  • Added a reconfiguration mode "Always" and "Never" to the Sick sensors. For example you can set this to "Never" and configure the sensor using SOPAS-ET.
  • Moved margin setting from the advanced device options to the screen settings. If you previously used a custom margin setting, you will have to set it again on the screen instead.
  • Added elliptical screen types.
  • Increased maximum TUIO cursor default from 10 to 100. This can be changed in the configuration file under config.tuio.cursor.max.
  • Reduce time spent locking sensor outlines on screen update. The sensor outline should no longer be locked during OpenGL calls. This should fix connection stability when the render thread is unable to run, for example when other applications switch to fullscreen.
  • Add support for LeiShen LS01B devices.

2019-01-26 1.2.3

  • Fix error causing Windows Touch input to fail with "The parameter is incorrect"
  • Fix serial port settings not correctly restoring in the GUI
  • Fix start angle calculation for Hokuyo sensors. This was a regression introduced in version 1.2.0 which caused certain models of Hokuyo sensors to be incorrectly rotated.
  • Disabled bilateral filter by default. Filter causes problems in certain situations and there is not enough benefit to keep it enabled. This can be reenabled in the advanced settings.
  • Replaced bitmap icons with vector icons. This makes the icons look better on high DPI systems or when the display is scaled up.
  • Adjusted UI to make more buttons fit.
  • Added new advanced settings window. This contains settings that usually do not need to be changed but can provide benefits in some situations.
  • Added new translations to Arabic, French, Portugese, Spanish and Thai.

  • Added option to ignore unknown version messages from Sick devices (default)
  • Check that the graphics card supports OpenGL 2.0

  • Fixed crash on loading older files without Windows Mouse mode setting
